# ניתוח וידאו סקוואט — כלי תרגול למאמן כושר

כלי מבוסס Computer Vision שמנתח תנועת סקוואט (מווידאו מוקלט מראש או ממצלמה חיה): מזהה שלד ונקודות גוף, מחשב את זווית הברך, סופר חזרות, ומודד את משכי הירידה והעלייה בכל חזרה. אפשר גם להגדיר יעד קצב אופציונלי (טווח שניות לירידה/עלייה) ולקבל עליו משוב.

**הכלי הזה לא נותן ציון טכניקה ולא קובע אם הביצוע "תקין"** — הוא מודד ומציג נתונים בלבד (זווית, קצב, השוואה ליעד קצב אם הוגדר), ומשאיר את השיפוט המקצועי למאמן.

## סטטוס נוכחי

פרויקט בתחילת דרכו, נבנה צעד-צעד:

- ✅ זיהוי תנוחה (pose estimation) על תמונה בודדת ועל GIF, כולל שרטוט שלד ונקודות גוף.
- ✅ חישוב זווית ברך דו-ממדית (אגן-ברך-קרסול) עם סף ביטחון וטיפול בנקודות חופפות.
- ✅ ספירת חזרות באמצעות מכונת מצבים (עמידה → ירידה → עומק → עלייה → עמידה), עם הגנה מפני ספירה כפולה ומפני אובדן זיהוי.
- ✅ מדידת משך ירידה/עלייה לכל חזרה, עם משוב קצב אופציונלי מול יעד שהמאמן מגדיר.
- ✅ בדיקות יחידה למנגנון הספירה והתזמון, עם רצפים מדומים (בלי צורך במודל).
- 🔲 סקריפט לניתוח חי ממצלמה (`live_squat.py`) — כתוב, אך **טרם נבדק בפועל מול מצלמה אמיתית**.
- 🔲 אין עדיין ממשק משתמש, אין שמירת היסטוריית אימונים, אין ציון טכניקה (ולא מתוכנן להיות).

## דרישות

- Python 3.14 (נבדק עם 3.14.7; ראו הערה על גרסאות אחרות בהמשך).
- [ultralytics](https://github.com/ultralytics/ultralytics) 8.4.x (מודל YOLO11-Pose)
- [opencv-python](https://github.com/opencv/opencv-python) 5.x
- מצלמת מחשב (רק לסקריפט הניתוח החי)

## התקנה

```bash
python3 -m venv venv
source venv/bin/activate      # ב-macOS/Linux
pip install --upgrade pip
pip install ultralytics opencv-python
```

מודל ה-Pose (`yolo11n-pose.pt`, כ-6MB) יורד אוטומטית בפעם הראשונה שסקריפט טוען אותו.

> **הערה על גרסת Python:** בפרויקט נבדק עם Python 3.14. אם אתם על גרסה אחרת (למשל 3.11–3.13) והתקנת `ultralytics`/`torch` נכשלת או מנסה לקמפל מקוד מקור, כדאי לנסות גרסת Python נפוצה/יציבה יותר (3.11–3.13) שיש לה בדרך כלל wheels בנויים מראש לכל התלויות.

## מבנה הפרויקט

```
scripts/
├── test_pose.py          # בדיקת זיהוי תנוחה על תמונה בודדת
├── test_pose_gif.py       # זיהוי תנוחה על כל פריימי GIF, שומר אנימציה עם שלד
├── knee_angle_gif.py      # חישוב זווית ברך על כל פריימי GIF + גרף זווית מול זמן
├── rep_logic.py           # הלוגיקה הטהורה: זווית, ספירת חזרות, תזמון, משוב קצב (בלי תלות ב-YOLO)
├── rep_counter_gif.py     # מריץ את rep_logic.py על GIF: אנימציה עם State+Reps, סיכומי חזרות, גרף עם נקודות
├── test_rep_counter.py    # בדיקות יחידה ל-rep_logic.py, עם רצפי זמנים/זוויות מדומים בלבד
└── live_squat.py          # ניתוח חי ממצלמת המחשב (OpenCV) - עדיין לא נבדק בפועל
```

## שימוש

### בדיקת זיהוי תנוחה על תמונה
```bash
python scripts/test_pose.py <נתיב לתמונה>
```
שומר עותק עם השלד ל-`<שם>_pose.<סיומת>`. התמונה צריכה להכיל אדם עם כל הגוף (כולל כפות רגליים) בפריים.

### זיהוי תנוחה על GIF
```bash
python scripts/test_pose_gif.py <נתיב ל-GIF>
```

### חישוב זווית ברך + גרף
```bash
python scripts/knee_angle_gif.py <נתיב ל-GIF>
```

### ספירת חזרות + תזמון + משוב קצב, על GIF
```bash
python scripts/rep_counter_gif.py <נתיב ל-GIF>
```
שומר אנימציה (`_reps.gif`) וגרף (`_reps_timing.png`), ומדפיס לקונסול סיכום לכל חזרה (משך ירידה/עלייה, ומשוב קצב אם הוגדר יעד ב-`PACE_TARGET` בראש הקובץ).

### ניתוח חי ממצלמה
```bash
python scripts/live_squat.py
python scripts/live_squat.py --side L                                  # לדלג על בחירה אינטראקטיבית
python scripts/live_squat.py --pace-descent 2.0 3.0 --pace-ascent 1.0 2.0  # להפעיל יעד קצב (כבוי כברירת מחדל)
```
בהפעלה: עומדים בצד למצלמה (כל הגוף וכפות הרגליים בפריים), בוחרים צד מדידה (L/R — נשאר קבוע לכל הסט), ועומדים ישר עד שהמערכת מזהה עמידה יציבה ומתחילה לספור. יציאה עם `Q`. **לא נשמר וידאו לדיסק.**

### בדיקות יחידה
```bash
python scripts/test_rep_counter.py
```
בודק את מנגנון הספירה, ההגנה מפני ספירה כפולה, הטיפול במדידות חסרות/אובדן זיהוי, מדידת התזמון, ומשוב הקצב — הכול עם רצפים מדומים, בלי להריץ מודל.

## הגדרות ניתנות לשינוי (`scripts/rep_logic.py`)

| קבוע | ברירת מחדל | משמעות |
|---|---|---|
| `STAND_ANGLE` | 160° | מעל זה נחשב "עמידה" |
| `DEPTH_ANGLE` | 100° | מתחת לזה נחשב "הגיע לעומק" |
| `CONFIRM_SEC` | 0.12s | זמן רציף נדרש לפני שמצב נחשב "מאושר" (מונע ספירה כפולה מרעידות) |
| `MAX_MISSING_SEC` | 0.5s | אובדן זיהוי רציף מעבר לזה מאפס התקדמות חלקית של חזרה |
| `PACE_TARGET_EXAMPLE` | ירידה 2–3s, עלייה 1–2s | **ערכי דוגמה לבדיקת התוכנה בלבד — לא המלצת אימון** |

כל הספים האלה ניתנים לשינוי בקוד לפי הצורך.

## הערות חשובות

- הזווית מחושבת רק כשלושת נקודות הגוף הרלוונטיות (אגן/ברך/קרסול, בצד אחד קבוע) מזוהות בביטחון ≥0.7; אחרת המדידה מסומנת כחסרה.
- יעד הקצב הוא כלי ניסוי אופציונלי בלבד — לא המלצת אימון ולא קביעה על איכות התרגיל.
- כשיש יותר מאדם אחד בפריים, הניתוח מושהה כדי לא לערבב בין אנשים.
